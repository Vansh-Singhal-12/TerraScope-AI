# Results

This directory contains experiment outputs and evaluation records.

## Pretraining

- `eurosat_training_history.json`: Training and validation metrics from EuroSAT pretraining.

## Transfer Learning

Results from the So2Sat transfer-learning experiments will be stored here.

These include:
- Model comparison metrics
- Per-class evaluation metrics
- Confusion matrices
- Training histories

Large model checkpoints are stored separately and are not committed to this repository.
