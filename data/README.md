
# Data

This directory contains dataset documentation and references.

## Datasets

### EuroSAT
Source: https://github.com/phelber/EuroSAT

Used as the source dataset for pretraining.

### So2Sat LCZ42
Source: https://github.com/zhu-xlab/So2Sat-LCZ42

Used as the target dataset for transfer learning.

## Storage

Raw datasets and processed data are not committed to this repository because of their size.

Download the required files separately and configure their local paths when running the project.
